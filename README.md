# Mobile_Sales_Analysis
Overview
An interactive Power BI dashboard that analyzes mobile phone sales across India. It turns raw transaction data from Excel into a view of sales performance, customer behavior and time-based trends, so a sales manager can spot top brands, strong cities and changes over time.

Dataset
The Excel file has one row per sales transaction. Its columns are:

Transaction ID
Day, Month, Year and Day Name
Brand and Mobile Model
Units Sold and Price Per Unit
Customer Name and Customer Age
City
Payment Method
Customer Ratings

Report pages

Dashboard (overview): KPI cards for Total Sales, Total Quantity, Transactions and Average, with a map of sales by city. It also has a line chart for trends, a funnel of ratings by rating status, a pie chart, a clustered bar chart, an area chart and a detail table.
MTD Report: a month-to-date view that tracks current-month performance with a trend line.
Same Period Last Year: a year-over-year comparison using a table and three clustered column charts.

Interactivity

Three dropdown slicers and a vertical tile slicer filter every visual on the page.
A page navigator on the left switches between the three pages.
Visuals cross-filter each other, so selecting a brand or city updates the rest of the page.

Skills demonstrated

Data modeling with a Sales_Data table and DAX measures (Total_Sales, Total_Quantity)
Time intelligence (month-to-date and same period last year)
KPI cards, map and funnel visuals, and slicer-driven filtering
Custom icons, rounded layouts and a consistent color theme

Tools: Power BI Desktop, DAX, Excel
